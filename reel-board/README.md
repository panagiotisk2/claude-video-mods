# Reel Board

A Claude Code mod with a `/reels` command that opens a side panel listing every Reel folder in the project's `content/` folder,
by post date, with a dot for each step (script, voice, avatar, edit, approved, caption, link; carousels have slides instead of
voice, avatar and edit) and the next step to do. It reads the files and NOTES.md of each folder, and has a Refresh button.

Built by asking Claude: "Make me a mod with a /reels command that opens a panel with every Reel I'm making and the step it's on."
